#Electricity Bill Calculator
A Python program that calculates residential electricity bills based on unit consumption and additional charges such as FPPPA, fixed charges, and government duty.

## Tariff Rates
- 0–50 units → ₹3.20/unit
- 51–200 units → ₹3.90/unit
- Above 200 units → ₹4.90/unit

## Features
- Slab-wise bill calculation
- FPPPA charges calculation
- Fixed charges addition
- Government duty calculation
- Detailed bill breakdown
